## 二、原生 App 滑動 vs Web App 滑動：技術差異

### 執行架構

```
原生 App：
手指接觸 → 螢幕合成器執行緒 (Compositor Thread) → 畫面更新
               ↑ 完全獨立於 App JS/邏輯，永遠不卡

Web App：
手指接觸 → JavaScript 主執行緒 → Layout → Paint → Composite → 畫面更新
               ↑ JS 一旦繁忙（解析 XML/查 DB），就會掉幀
```

### 特性對比表

| 特性 | 原生 App | 目前 Web App | 可改進？ |
|------|----------|-------------|---------|
| **頁面跟手指比例** | 1:1 完全跟隨 | 0.65（只移 65%） | ✅ 改為 1.0 |
| **執行緒** | 合成器執行緒 | JS 主執行緒 | ⚠️ 只能靠 `transform`/`opacity` 接近 |
| **甩動物理（Velocity）** | 有：放手速度決定動畫速度與距離 | 無：固定 0.24s | ✅ 可實作 |
| **快速甩動低門檻** | 有：速度快時距離閾值降低 | 無：固定 28px | ✅ 可實作 |
| **橡皮筋效果（Rubber-band）** | 有：到邊界會伸縮彈回 | 無 | ✅ 可實作（較複雜） |
| **中途攔截動畫** | 可隨時抓住飛行中的頁面重新拖 | 無 | ✅ 可實作 |
| **120Hz ProMotion** | 自動啟用 | 無法控制 | ❌ OS 決定 |
| **觸控預測（Touch Prediction）** | OS 層預測手指下一位置 | 無 | ❌ 瀏覽器不開放 |

## 三、最關鍵的改進方案

### 改進 1：1:1 跟手指（最重要）

原生 App 的核心感覺來源：頁面完全跟著手指，沒有縮減。

```ts
// 目前（只跟 65%，有點「沉重」感）
`translateX(${deltaX * 0.65}px)`

// 改進（1:1 完全跟隨，輕盈自然）
`translateX(${deltaX}px)`
```

---

### 改進 2：速度物理（Velocity Physics）

**原生 App 的核心秘密：放手速度 = 動畫速度**

```
慢慢滑 → 動畫慢（細膩、拖得住）
快速甩 → 動畫快（爽快、俐落）
```

目前 Web App 不管你滑多快多慢，動畫都是固定 `0.24s`，這是「不自然」的主因。

**實作方式（需加入 touchSwipeRef）：**

```ts
// touchStart 時記錄起點，新增速度追蹤欄位
touchSwipeRef.current = {
  x, y, time: Date.now(),
  lastX: x, lastTime: Date.now(), velocityX: 0
};

// touchMove 時滾動更新「最近速度」（只記最後一次有效取樣）
const now = Date.now();
const elapsed = now - touchSwipeRef.current.lastTime;
if (elapsed > 20) {  // 每 20ms 取樣一次
  touchSwipeRef.current.velocityX =
    (currentX - touchSwipeRef.current.lastX) / elapsed; // px/ms
  touchSwipeRef.current.lastX = currentX;
  touchSwipeRef.current.lastTime = now;
}

// touchEnd 時依速度決定動畫時長
const velocity = Math.abs(touchSwipeRef.current.velocityX || 0); // px/ms
const screenWidth = window.innerWidth;
const remaining = screenWidth - Math.abs(deltaX); // 剩餘要飛的距離
const duration = Math.min(320, Math.max(80, remaining / (velocity || 0.5)));
// → 快速甩：80ms 閃過；慢速拖：最多 320ms 優雅滑入
```

### 改進 3：快速甩動低門檻（Fling Detection）

```ts
const VELOCITY_THRESHOLD = 0.3; // px/ms（速度夠快時）
const velocity = Math.abs(touchSwipeRef.current.velocityX || 0);

// 速度快 → 只需 15px 就觸發（自然甩動感）
// 速度慢 → 需要 28px 才觸發（避免誤觸）
const distanceThreshold = velocity > VELOCITY_THRESHOLD ? 15 : 28;

const isValidSwipe = Math.abs(deltaX) > distanceThreshold
  && Math.abs(deltaX) > Math.abs(deltaY) * 1.15
  && deltaTime < 550;
```

---

### 改進 4：橡皮筋邊界（Rubber-band）

到達頁鏈的最左或最右端時，仍可拖動但有阻力感：

```ts
// 在邊界時，跟隨比例縮小（越拉越重，像橡皮筋被拉伸）
const isAtEdge = /* 判斷：deltaX > 0 且已在首頁，或 deltaX < 0 且已在最後一頁 */;
const screenWidth = window.innerWidth;
const ratio = isAtEdge
  ? 0.25 / (1 + Math.abs(deltaX) / screenWidth * 2)  // 越拉越重
  : 1.0;  // 正常 1:1

container.style.transform = `translateX(${deltaX * ratio}px)`;
// 鬆手後：用 spring 曲線彈回 translateX(0)
```
